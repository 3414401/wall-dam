# AI 조 배치 참고 자료

이 파일을 수정하면 **AI 조 배치**와 **동질성 분석** 때 항상 참고합니다.
GitHub에 push한 뒤, 다음 AI 조 배치부터 반영됩니다.

## 엑셀 파일 (추천)

아래 **둘 중 하나**를 GitHub `data/` 폴더에 올리면 AI가 표 전체를 읽습니다.

| 파일 이름 | 설명 |
|-----------|------|
| `data/ai-reference.xlsx` | 엑셀 통합문서 (여러 시트 가능) |
| `data/ai-reference.csv` | CSV (엑셀에서 다른 이름으로 저장 가능) |

템플릿 예시: `data/ai-reference.template.csv` 를 엑셀로 연 뒤
이름을 `ai-reference.xlsx` 로 저장해 `data/` 에 업로드하세요.
